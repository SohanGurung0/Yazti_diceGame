# 3D Yahtzee: Office Desk Edition

A premium, 3D web-based Yahtzee game built with React and Three.js. This edition features a minimalist "Office Desk" aesthetic with high-fidelity 3D dice, reflective surfaces, and smooth animations.

## Features

- **High-Fidelity 3D Graphics**: Realistic 3D dice simulation using Three.js.
- **Dynamic Camera**: Intelligent camera movements that focus on the action.
- **Multiplayer Support**: Local multiplayer for up to 4 players.
- **Mobile Responsive**: Fully optimized for mobile devices (portrait and landscape).
- **Interactive Scorecard**: Sleek, glassmorphism-style scorecard with live point previews.
- **Premium UX**: Smooth transitions, haptic-style animations, and confetti celebrations.

## Tech Stack

- **React**: UI components and game state management.
- **Three.js**: 3D engine for dice and environment rendering.
- **Tailwind CSS**: Styling and responsive layout.
- **Babel**: JSX compilation for a seamless development experience.
- **Canvas Confetti**: Celebratory effects for the winner.

## How to Play

1. **Start Game**: Choose the number of players (currently optimized for 2 players).
2. **Roll Dice**: Click the "Roll Dice" button to shake and throw the 3D dice. You have 3 rolls per turn.
3. **Hold Dice**: Click on individual dice to keep them for the next roll. Held dice will float and spin.
4. **Select Score**: Once you're happy with your roll (or run out of rolls), open the "Point Table" or click "Select Point" to choose a category.
5. **Win**: The player with the highest total score after all categories are filled wins the game!

## Installation & Running

This is a client-side web application. No complex setup is required.

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Alternatively, serve it using a local server (like Live Server in VS Code).

## Mobile Optimization

The game is designed to scale beautifully across all devices:
- **Portrait Mode**: The 3D camera adjusts to provide a top-down view of the dice.
- **Touch Friendly**: All controls are oversized and optimized for thumb-reach.
- **Single-Column Scorecard**: Categorized points are stacked for better readability on narrow screens.
